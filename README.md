A ROS 2-based indoor cargo-carrying robot prototype featuring hybrid AMR-AGV operation

ROS 2 tabanlı, hibrit AMR-AGV çalışma prensibine sahip, iç mekanlarda yük taşıyabilen bir robot prototipi.
